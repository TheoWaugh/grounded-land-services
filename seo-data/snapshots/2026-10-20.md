## Tracking gaps found
1. **GA4 records no conversion events.** Phone clicks and the quote form only fire Meta Pixel (`fbq`), not `gtag`.
   That means GA4 can't report leads by source.
2. Only the **desktop header** phone link fires an event. The mobile menu, footer, contact page, homepage and FAQ
   `tel:` links don't. Most calls come from phones, so most calls go untracked.
3. `app/layout.tsx` has **two `<Script id="meta-pixel">` tags**, and the first one is empty. Next.js loads
   only one script per id, so the real pixel may never load. Check in Meta Events Manager or with the
   Meta Pixel Helper extension.
→ Fix 1–3 with `/conversion-optimize`.
